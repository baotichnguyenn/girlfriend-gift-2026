# Museum of Us

A scroll-driven 3D museum walk. A small figure of her follows a brass path and opens five letters in a fixed order. Velvet ropes block the way until each letter is read.

- Run: `python3 -m http.server 8000`, then open http://localhost:8000
- Edit the letters, her name, and her photo in `CONFIG` at the top of the script in `index.html`
- Prototype tools: add `#edit` to the URL

See `DESIGN.md` for the design and `CLAUDE.md` for how the code is organised.

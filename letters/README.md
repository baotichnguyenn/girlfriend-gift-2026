# Letters

Each file here is one letter, in the order she must read them: `1.txt` is Letter I, through `5.txt` for Letter V.

- Every line is a paragraph. Blank lines are ignored, so leave them between paragraphs if that's easier to read.
- The first line can be `Title: …`. It sets the letter's title on its placard, prompt, and paper. Leave it out to keep the title in `js/config.js`.
- Text in `[square brackets]` shows highlighted, as a reminder of what's still to write.
- Save as UTF-8 (Notepad's default), so Vietnamese accents show correctly.
- If a file is missing, that letter uses the text in `js/config.js`.
